# wetto-midia

Mídias já aprovadas pelo WETTO para publicação no Instagram.

## O que entra aqui

- Somente arte e vídeo que o Welton aprovou.
- Nada de rascunho, texto de legenda, letra de música ou material de trabalho.

## O que não entra aqui

- Letras inéditas.
- Segredos, chaves ou tokens.
- Qualquer conteúdo que ainda não foi aprovado.

## Como o Instagram usa este repositório

A API do Instagram busca a imagem ou o vídeo por um endereço público. Os arquivos aprovados ficam acessíveis pelo GitHub Pages deste repositório.

Este repositório é público. Tudo que estiver aqui pode ser visto por qualquer pessoa.
